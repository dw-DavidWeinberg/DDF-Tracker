# 🔍 Die drei ??? Tracker

Überarbeiteter Fork von mycollectos Lesetracker (https://mycollecto.github.io/drei-fragezeichen-tracker/) für alle Die drei ??? Bücher und Hörspiele.

Geplante Feature:
- 📚 **Alle Fälle** sortiert in ihre eigenen Rubriken
- 📋 Mehrere Listen zum Abhaken: "besitze ich", "gehört", "gelesen", "als nächstes"
- 🖼️ Echte Cover vom Fandom-Wiki und Kosmos für die Bücher
- 🖼️ CD Cover vom Fandom-Wiki und Kosmos für die Hörspiele
- 🛒 Amazon oder Thalia Kaufen-Links zu den Büchern
- 🎧 Spotify Links zu den Hörspielen
- 💾 Fortschritt lokal gespeichert
- 📱 PWA – auf Homescreen installierbar

## Reihenfolge
## Bücher
Die App folgt der **offiziellen Kosmos-Reihenfolge** – bestätigt durch den Kosmos-Verlag und dokumentiert auf Wikipedia.

- Bände 1–55: US-Originale in Kosmos-Reihenfolge (weicht von Hörspiel-Zählung ab)
- Band 56+: Deutsche Fortsetzung (Kosmos-Nummerierung)
- Jubiläumsbände 100, 125, 150, 175, 200 = je 3 Teile unter einer Nummer

## Hörspiele
Die Hörspiele folgen der Sortierung von Europa
